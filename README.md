# TAMTA Studios

A cinematic creative studio platform built as a real full-stack product.

## Architecture
- Next.js App Router — web + API
- Zod — API validation
- Agent layer — future LangGraph orchestration
- MCP layer — future standardized business-tool access
- Production integrations — payments, WhatsApp, storage, auth and database to be added behind server-side APIs

## Development principle
Build and verify the smallest production-safe slice first, then add business capabilities one at a time. No secrets are committed to GitHub.
