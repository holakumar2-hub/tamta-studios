# TAMTA Studios

A cinematic creative studio full-stack website foundation.

## Stack
- Next.js
- React
- TypeScript
- Prisma/PostgreSQL
- Razorpay payment foundation
- LangGraph agent foundation
- MCP server architecture

## Development
```bash
npm install
npm run dev
```

## Environment
Copy `.env.example` to `.env` and add the required values before enabling database, payment, and AI integrations.
